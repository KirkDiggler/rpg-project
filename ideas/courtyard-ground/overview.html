Courtyard ground

A region owns its base look. Paint changes selected existing hexes, not where actors can walk.

Story #867 · Design · Implementation plan

One value, source to screen

Private Assets supplies the renderer's reviewed, hash-bound color resources. The engine carries opaque appearance refs; it does not download textures or interpret dirt as a movement cost.

The rules you can see

  • Unpainted regions keep the existing stone appearance.
  • Changing a base keeps explicit paint. Erasing paint exposes the current base.
  • Appearance cannot create floor, change a region, lift an actor or disclose a hidden cell.
  • Textures continue in world space rather than restart on each hex.
  • An unavailable explicit style is an error, not a silent stone fallback.
