# Slice: the repository

> The spike files this plan copies from were removed from this repository after the slice; they read at [the commit that held them](https://github.com/KirkDiggler/rpg-project/tree/f24359d38617b4c9b30f833ddc621efcd94f6f08/ideas/unreal-client/spike).

The second step of [the shape on the design PR](https://github.com/KirkDiggler/rpg-project/pull/1155#issuecomment-7184548947):
a public repository, `rpg-dnd5e-unreal`, built from the spike's keepers,
that builds and tests from a clean checkout. Law: [design.md](design.md)
R1, R5, R6, R7. The first step of that shape, the pipeline (R2, `gen/cpp`
in the protos repository, R3), waits on the operator's boxes; until then
this repository fetches what the spike fetched, by script, and says so.

## Goal and scope

A player of this workspace clones `rpg-dnd5e-unreal` beside the other
repositories, runs one script, and can build the editor target and run the
tests on Linux. In scope: the repository, the project named R7, the core
and the beat-reading with their tests, the fetch scripts, the instructions
for people and agents. Out of scope, each a later slice: the pipeline's own
C++ target and a build of gRPC for the engine's toolchain (R2, R3), a game
mode, content by reference beyond the mount point, CI that builds the
engine, platforms other than Linux.

## Finish line

- `KirkDiggler/rpg-dnd5e-unreal`, public, MIT, on `main`, with README,
  CLAUDE.md and AGENTS.md (a symlink), `.gitignore`, `.gitattributes`.
- `RpgDnd5eUnreal.uproject` at the root; a thin game module; one plugin,
  `RpgWire`, with two modules: `RpgWire` (the core) and `RpgClient` (the
  beat-reading).
- Nothing generated, binary or licensed is committed: the generated
  contract, the libraries and any content plugin are fetched by script into
  ignored paths, each script pinning what it takes.
- From a clean clone: `scripts/bootstrap.sh && scripts/build.sh &&
  scripts/test.sh` passes: the beat-reading tests green; with the engine's
  test server running, the verb tests green too.
- The run record on the design PR.

## Authority

design.md R1, R5, R6, R7 (settled, KirkDiggler); the operator's "let's get
started" (2026-11-26, in session).

## Constraints

- No Synty, GLB, FBX or engine content in the repository (workspace hard
  rule; R6). Code, config, scripts and original text only.
- Nothing generated is edited by hand (design Law): the fetch script applies
  the R2 rename as a step, and the step disappears when R2 lands.
- Blocking calls off the game thread; the core names no Unreal type beyond
  the export macro (as the spike has it).
- Attribution as the active Team; signature `— platform agent, on behalf of
  KirkDiggler`.
- Each `.cpp` includes what it uses; the per-file check ships as a script.

### Task 3: The scripts

**Delivers:** one command from a clean clone to a built, tested project.
**Files:** `scripts/bootstrap.sh`, `scripts/fetch-deps.sh`,
`scripts/fetch-protos.sh`, `scripts/mount-content.sh`, `scripts/build.sh`,
`scripts/test.sh`, `scripts/perfile-check.py`, `buf.gen.yaml`.
**Interfaces:**
- `fetch-deps.sh`: downloads TurboLink release v1.4.2's `TurboLink.UE56.zip`
  (sha256 `9ad1ecd9e64d4166fff973bcb5b3f493756987a99f2d3c2e9933b9c2908eaf39`),
  cached under `~/.cache/rpg-dnd5e-unreal/`, and extracts only
  `Source/ThirdParty/{grpc,protobuf,abseil,re2}` into the plugin. Stops, and
  says why, if the hash differs. Documented as the stopgap until R3.
- `fetch-protos.sh`: `buf generate` from `$RPG_API_PROTOS_DIR` (default
  `../rpg-api-protos`) at whatever ref is checked out, with the repository's
  `buf.gen.yaml` (cpp v23.4, grpc v1.57.0); flattens names into
  `Private/pb/` as the spike did; applies R2's rename; writes
  `Private/pb/SOURCE` with the protos commit and the plugins' versions.
- `mount-content.sh`: if `../rpg-game-assets/unreal/RpgGameAssets` exists,
  links it at `Plugins/RpgGameAssets`; says so; never fails a build.
- `build.sh`, `test.sh`: the engine from `$UE_ROOT` (default
  `~/UnrealEngine/UE_5.9`); `test.sh` runs the beat-reading tests always and
  the verb tests when `RPGWIRE_TEST_ADDR` is set.
**Tests:** from a clean clone, Task 4.

- [ ] Write; try each once by hand; commit.
