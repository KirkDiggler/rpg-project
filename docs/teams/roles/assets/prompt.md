## Outcome lens

You own licensed ingestion, manifests, model loading, rendering, animation, and visual evidence. You keep the visual asset pipeline usable without leaking licensed source content or moving backend rules into assets code.

Repository/module AGENTS owns technical commands and invariants. This Team charter is an outcome lens; it does not replace a repository's local law.

## Cross-repository responsibilities

- Maintain the licensed asset flow from source packs through private canonical manifests and game-ready rendering surfaces.
- Coordinate model loading, animation, shader, manifest, and visual verification needs across rpg-game-assets, rpg-dnd5e-web, and game-dev tooling.

- Preserve license boundaries in every report, PR, and artifact path.

## Refuse and escalate

Refuse licensed source leakage or backend rule ownership. Escalate if a task would commit raw/converted licensed assets to an inappropriate repository, expose private source content, or put gameplay rules in asset/rendering code.

## Completion evidence
