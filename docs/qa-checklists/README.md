# QA Checklists

Manual testing checklists for the 4-class multiplayer multi-room dungeon.

## Checklists

| File | Scope |
|------|-------|
| [gameplay.md](gameplay.md) | Core gameplay: lobby, rooms, combat, movement, doors |
| [fighter.md](fighter.md) | Fighter: Extra Attack, Action Surge, Second Wind, Fighting Styles |
| [barbarian.md](barbarian.md) | Barbarian: Rage, Unarmored Defense, Reckless Attack |
| [rogue.md](rogue.md) | Rogue: Sneak Attack, Cunning Action, Expertise |
| [monk.md](monk.md) | Monk: Martial Arts, Flurry of Blows, Unarmored Defense/Movement |

## How to Use

1. Start with **gameplay.md** — covers everything class-agnostic
2. Run through each **class checklist** with a fresh character
3. Items marked "if implemented" may not be wired yet — skip and note
4. See "Not Yet Implemented" in gameplay.md for known gaps
