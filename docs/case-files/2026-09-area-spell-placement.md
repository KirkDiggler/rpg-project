# Case file — the area-spell placement, and the ownership test

**This is not law.** It is the case file behind the ownership-test doctrine in
`rpg-project/CLAUDE.md` ("Mistakes are not the problem"). Kept because the
reasoning is the useful part; kept *here* because reasoning that rides along
in a doc every session loads stops teaching and starts steering. Load it when
the rule alone does not stop the wrong move.

## The incident

An area spell's target derivation was designed into `session` for two drafts.
The seam doc already said *"geometry, placement → `encounter`"*, but the work
did not read as *geometry* from inside — it read as *deriving a target set* —
and the predicate/producer rule beside it is a **mechanism** test that a
`session`-side fold passes cleanly. The rule licensed the error rather than
catching it.

The fix was not "remember that placement is encounter's"; it was to add an
**ownership test** ahead of the mechanism test in all three seam docs, so the
wrong answer now looks wrong on the page.

## Why the shape mattered while small

Today a misplaced responsibility is visible in an afternoon. That will not
last, and the same mistake in a system three times this size is not caught by
being careful — it is caught by the seams and the rules being clear enough
that the wrong answer cannot look reasonable.
