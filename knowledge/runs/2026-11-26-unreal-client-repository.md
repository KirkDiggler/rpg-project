## Decided

- The repository's root is the project's root, and the project is named after the repository in PascalCase with the initialism as a word, because that is the engine's own practice (`HttpBlueprint`, `FJsonObject`, `TcpMessaging`) and the web's naming practice; an initialism in capitals is the engine's exception — [R7](../../ideas/unreal-client/design.md#rulings).
- The repository is public and holds no licensed content; the Unreal format of it lives in `rpg-game-assets` and is mounted, never committed — [R6](../../ideas/unreal-client/design.md#rulings).
- The compiled contract is generated by script from the protos beside the main checkout, with R2's rename applied to a copy of the *sources* rather than to generated C++, because a field's name is not on the wire and a patched generated file is a file edited by hand; the step counts the fields and stops loudly when R2 lands — [fetch-protos.sh](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/fetch-protos.sh).
- The libraries are a pinned archive, sha256 checked, with none of the archive's own code taken: a stopgap until R3's own build, said so where it is taken — [fetch-deps.sh](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/fetch-deps.sh).
- The labs stay behind as the spike's record; the core and the beat-reading are carried, and the beat-reading's tests are renamed for their module, `RpgClient.Motion.*` — [rpg-dnd5e-unreal#1](https://github.com/KirkDiggler/rpg-dnd5e-unreal/pull/1).

## Found

- The TurboLink release archive is the plugin at its root, with no wrapper folder; its headers and Linux libraries in both configurations are 1.1 GB — [fetch-deps.sh](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/fetch-deps.sh).
- `buf generate` from a `git archive` of the protos at `03cfdee`, with `cpp:v23.4` and `grpc/cpp:v1.57.0`, yields 72 sources and 72 headers in 24 seconds, and protobuf 4.23.4 and gRPC 1.57.0 are what the archive vendors — [fetch-protos.sh](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/fetch-protos.sh).
- From a clean clone: bootstrap in 8 seconds with the archive cached, the build in 106, fourteen tests green, every hand-written file compiled alone, and `git status` clean — [rpg-dnd5e-unreal#1](https://github.com/KirkDiggler/rpg-dnd5e-unreal/pull/1).
- In a worktree a sibling looked up by `../` lands inside `.worktrees/`; the main checkout is where git's common directory is — [fetch-protos.sh](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/fetch-protos.sh).
- Under `pipefail` a lookup that finds nothing ends a script with no word; the scripts now say what each step found — [fetch-deps.sh](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/fetch-deps.sh).
- The engine ships .NET for several architectures, and the one to run is the machine's own — [perfile-check.py](https://github.com/KirkDiggler/rpg-dnd5e-unreal/blob/from-the-spike/scripts/perfile-check.py).
