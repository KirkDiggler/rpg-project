# Milestone: 4-Class Multiplayer Multi-Room Dungeon

The current milestone. Four classes (Fighter, Barbarian, Rogue, Monk) fight through multi-room dungeons together in a Discord Activity.

## Project Board

## Scope

Three pillars:
1. **Multi-Room Dungeons** - Absolute positioning, room transitions, doors
2. **Combat System** - Action economy, death saves, reactions
3. **Quality & Polish** - Multiplayer events, pathfinding, UI components
